# jukette

A white-label jukebox custom element exposed as `<jukette-player>`.

Jukette v0.9.0

By Rémino Rem  
<https://remino.net/>

[Docs](https://remino.net/jukette/) |
[Code Repo](https://github.com/remino/atelier) |
[npm Package](https://www.npmjs.com/package/jukette)

---

## Installation

```sh
npm install jukette
```

For MIDI or SoundCloud support, also install the matching addon packages:

```sh
npm install @remino/jukette-midi @remino/jukette-soundcloud
```

## Usage

```js
import 'jukette/auto'
```

See the [Jukette documentation](https://remino.net/jukette/) for playlists,
backends, API details, and styling.
